# Security

Please report security vulnerabilities privately. Do not open a public GitHub issue, and do not include exploit details in pull requests or discussions.

Use a [private security advisory](https://github.com/kkofor/vanstro-frontend/security/advisories/new) on this repository. Include:

- A description of the issue and the impact you can see
- The files, routes, or commits involved
- Steps to reproduce, without attaching live credentials or customer data

We will acknowledge reports that include enough detail to reproduce the issue. Please give us time to investigate before any public write-up.
