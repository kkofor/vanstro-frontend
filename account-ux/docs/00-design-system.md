# 00 · 设计规范（源自《万拓品牌视觉白皮书》）

适用范围：vanstro.ca 账户体系（登录 / 忘记密码 / 个人中心）。所有令牌已落地在 `assets/vi.css`，可直接引入前端工程。

## 1. 品牌色与界面职责

白皮书给出四个品牌色、一个字族与深色底反白稿规则。界面比印刷物料多出「状态」这一维度：加载、禁用、错误、成功都需要颜色表达，而白皮书未定义错误色。下面把四个品牌色分配到明确职责，未覆盖的部分逐条登记为例外。

### 1.1 品牌色（白皮书原值）与职责

| 名称 | HEX | CMYK | 界面职责 |
|---|---|---|---|
| 深藏青 | `#004744` | 100 / 53 / 67 / 41 | **主色 `--vs-navy`**：主按钮、链接、焦点环、进度条、选中态（开关、分段、导航）。反白文字取纯白，与白皮书「反白稿」一致。hover / pressed 用 `navy-700 #003431` |
| 豆绿灰 | `#9BA8A2` | 45 / 28 / 35 / 0 | **中性色系的取色来源**。页面底 `#F1F4F3`、次级填充 `#E9EDEB`、描边 `#D2DAD8 / #B9C3C0` 与三级文字灰 `#0A1614 / #3C4B48 / #6D7C79` 全部沿豆绿灰色相偏移，因此界面的灰不是纯灰，与物料同一家族。原值本身只用于占位符 |
| 青翠绿 | `#0D8968` | 82 / 30 / 69 / 0 | **成功语义 `--vs-success`，仅此**：保存成功、验证通过、密码强度达标、`Delivered` 徽章。与主色在色相上拉开，不与「主按钮」混淆；因此不做焦点环、不做按钮。深色底上的标语（白皮书「常用于深色底」）是唯一的非状态用法 |
| 暖阳橙 | `#F5A93F` | 0 / 42 / 78.5 / 0 | **少量、仅图形**：会员等级徽章底、密码强度中档条、流程图警告分支描边、装饰三角。不用于按钮、大面积填充和任何文字。需要橙色文字 / 图标时改用加深版 `--vs-orange-ink #8A5A0B`（白底 4.9:1；原值仅 1.9:1，不可读） |
| 深色底 | `#021816` | 白皮书深色底取样 | 登录页品牌区、Toast、浮动保存条（配反白稿 Logo）。深色底上的主色 CTA 取提亮版 `#4AA8A2` 配深色文字 |

### 1.2 令牌映射（`assets/vi.css`）

| 令牌 | 值 | 依据 |
|---|---|---|
| `--vs-navy` / `--vs-navy-700` / `--vs-navy-900` | `#004744` / `#003431` / `#021816` | 深藏青原值、加深、白皮书深色底 |
| `--vs-navy-50` (brand-soft) / `--vs-navy-100` | `#E0EBE9` / `#C4D7D4` | 选中导航底、info 横幅 |
| `--vs-grey-50` (ground) · `-100` · `-150` · `-200` (line) · `-300` (line-2) | `#F1F4F3` · `#E9EDEB` · `#DBE2E0` · `#D2DAD8` · `#B9C3C0` | 豆绿灰色相延伸 |
| `--vs-text` · `-2` · `-3` | `#0A1614` · `#3C4B48` · `#6D7C79` | 同上；text-3 白底 4.6:1 |
| `--vs-green` / `--vs-green-50` / `-100` | `#0D8968` / `#DEEFE9` / `#BFE2D3` | 青翠绿原值与浅底 |
| `--vs-orange` / `--vs-orange-50` / `--vs-orange-ink` | `#F5A93F` / `#FDEFDB` / `#8A5A0B` | 暖阳橙原值、浅底、加深版（文字） |
| `--vs-focus` | `0 0 0 3px rgba(0,71,68,.28)` | 焦点环取主色，键盘可见性的唯一依赖 |
| 阴影 | `rgba(0,71,68,…)` | 阴影带主色色相，与豆绿灰卡面同族 |

### 1.3 例外登记（白皮书未定义，需品牌方确认）

| 项 | 取值 | 说明 |
|---|---|---|
| 错误色 | `--vs-error #B3261E` · `--vs-error-50 #F8E2E0` | 表单错误、危险操作、拒付。白底 6.1:1。色相偏红以与暖阳橙区分 |
| 警告文字色 | `--vs-warning` = `--vs-orange-ink #8A5A0B` | 警告横幅文字与图标；底色沿用 `orange-50` |
| 等宽字体 | IBM Plex Mono → ui-monospace | 错误码、验证码、脱敏号码、金额对齐 |
| Logo 最小尺寸与安全边距 | 高 ≥ 20px；四周留白 ≥ 高度 50% | 见 §3 |

这四项是可用的工程默认值，不是品牌决策。

## 2. 字体

- 白皮书指定 **HarmonyOS Sans Bold** 用于标语与标题；本设计将其用于 H1–H3、按钮、标语。
- 正文与表单使用同字族 Regular / Medium。
- Web 回退栈：`"HarmonyOS Sans", "Inter", -apple-system, "Segoe UI", Roboto, "PingFang SC", sans-serif`。上线前需将 HarmonyOS Sans 以 `@font-face` 自托管（woff2）。
- 字号阶：12 / 13 / 14 / 15 / 20 / 26 / 28–32 px。字距：标题 −0.01em，标语 +0.28em 大写。

| 角色 | 字号 / 行高 / 字重 | 用途 |
|---|---|---|
| Display | 28–32 / 1.15 / 700 | 登录、注册 H1 |
| H2 | 26 / 1.2 / 700 | 个人中心分区标题 |
| H3 | 20 / 1.25 / 700 | 卡片标题 |
| Body | 15 / 1.55 / 400 | 正文、输入框 |
| Small | 13 / 1.5 / 400–600 | 标签（700）、帮助、表格 |
| Caption | 12 / 1.5 / 400 | 错误、脚注、法务 |
| Eyebrow | 11.5 / 1 / 700 / +0.04em 大写 | 表头、状态芯片 |

- 等宽（`--vs-mono`：IBM Plex Mono → ui-monospace）：**只用于**订单号 / 报价号、OTP、错误码、IP、脱敏号码。金额不用等宽，用 `font-variant-numeric: tabular-nums`。白皮书未定义，属例外登记。

## 3. 标识用法

| 场景 | 版本 | 文件 |
|---|---|---|
| 浅色底（表单区、站点导航） | 标准英文标识 · 深藏青 | `assets/brand/logo-navy.png` |
| 深色底（登录页品牌区、深色 Toast） | 反白稿（绿色平行四边形底 + 白 VA + 橙块 + 白字，品牌书「使用辅助图形需出现公司全称搭配主标识反白稿」） | `assets/brand/logo-reverse.png` |
| 深色底强调（不常用） | 辅助色青翠绿 | `assets/brand/logo-green.png` |
| 单标（浅色底） | VA 符号 · 深藏青 + 暖阳橙 | `assets/brand/mark.png` |
| 背景装饰（深色底） | VA 符号纯白稿，≤ 7% 透明度 | `assets/brand/mark-white.png` |

2026-09 起使用完整组合标（VA 符号 + VANSTRO + GLOBAL SUPPLY 字标），源文件 1024 × 184 JPG 黑底，已抠图为透明 PNG；符号内暖阳橙梯形在所有稿中保留原色，不随反白变化。

规则：组合标尺寸对齐主站 www.vanstro.ca：导航 36px、品牌区与页脚 38px（主站实测 178×36 / 190×38）；四周留白 ≥ 标识高度的 50%；辅助图形仅作低透明度（≤ 12%）背景装饰，且同版面须出现公司全称 “Vanstro Global Supply Inc.”（白皮书要求）。

## 4. 组件令牌

| 令牌 | 值 |
|---|---|
| 控件高度 | 46px（`--vs-control-h`）；小号 36px |
| 圆角 | 输入 / 按钮 8px；卡片 12–16px；芯片 999px |
| 描边 | 1px `#D2DAD8`；hover `#B9C3C0`；focus 深藏青 `#004744` + 3px 28% 焦点环（错误态 `#B3261E` 22%） |
| 阴影 | 带主色色相 `rgba(0,71,68,…)`：sm `0 1px 2px .06 + 0 8px 24px -16px .34`；md `0 8px 24px .12`；lg `0 12px 40px -12px .40` |
| 间距 | 4 / 6 / 10 / 14 / 18 / 22 / 26 px |
| 动效 | 150ms ease（颜色 / 描边）；250ms（面板切换）；仅使用 transform / opacity |

### 按钮

- Primary：深藏青底白字，hover `#003431`。
- Secondary：白底深藏青描边。Ghost：透明。Accent：白底深藏青字，仅用于深色底（品牌区、保存条）上的 CTA；深色保存条上的主按钮取提亮版 `#4AA8A2` 配深色文字。青翠绿只表达成功，不做按钮。Danger：白底错误红描边。
- Google / Apple：遵循各自品牌指南，不重新着色（Google 白底 `#DADCE0` 描边 + 官方 G 图标；Apple 黑底白 Logo）。

### 表单

- 标签在上，13px/700；帮助文案 12px 灰；错误文案 12px 错误红 + 图标，紧贴输入框下方。
- 错误时描边变红，焦点环变红 22%。成功（如两次密码一致）描边变青翠绿：这是青翠绿在表单中唯一的出现位置。
- 输入框内左侧图标 18px；右侧动作按钮（眼睛）34×34 点击区。
- 标识符输入框右侧显示实时识别芯片：`Email` / `Mobile · CA` / `Username`。

### 反馈

- 横幅（alert）：error / warning / success / info，四色底 + 左侧图标 + 加粗标题 + 一行说明 + 行内链接。
- Toast：深色底白字，青翠绿图标，屏幕底部居中 3.2s 自动消失。

## 5. 布局

- 登录 / 注册 / 忘记密码：双栏（40% 品牌区 + 60% 表单区），表单最大宽 420px；≤ 900px 时隐藏品牌区并在顶栏显示标识。
- 品牌区底色：**深藏青纯色 `#004744`**（参考稿取样 `#114744`，与白皮书主色一致），不用渐变；装饰为右下 4.5% 白色大圆 + 7% VA 单标；标语用 `--vs-green-100` 浅绿（原值青翠绿在藏青上对比不足）；价值点勾选图标用暖阳橙（深色底上橙做图形色）。
- 个人中心：1200px 容器，250px 侧栏 + 内容区；≤ 960px 单栏。
- 断点：`≤ 900px` 隐藏品牌区；`≤ 960px` 侧栏折叠为顶部横向导航、双栏说明块（`.explain / .note-2`）变单栏、表格隐藏 `.hide-sm` 列；`≤ 640px` 表单双列变单列，按钮 `btn--block`。
- 结算：720px 表单 + 360px 订单摘要（sticky）；≤ 960px 摘要折叠为顶部可展开条。
- 顶栏右侧固定：EN | FR 切换器（胶囊）。
- **站点页脚（个人中心、结算）**：嵌入主站 www.vanstro.ca 页脚，由 `assets/site-footer.js` 渲染到 `<footer class="site-footer" data-site-footer>`，样式在 `assets/vi.css`「Site footer」段。结构与主站一致（2026-09-03 取样）：白底、1536px 容器；左栏 360px = 藏青标识 38px + 橙色小题「YOUR GLOBAL SUPPLY PLATFORM」（11px/800/字距 .14em，两侧橙短线）+ 地址 / 邮箱 / 电话（橙墨图标 14px）+ 5 个 34px 藏青圆形社媒按钮；右侧 4 栏 Shop / Customer Support / Dealer Program / Company（标题 14px/700，链接 13px）；底部法务条 `#f4f5f5` 底、`#d9e1df` 上边线、12px，左版权（EN | FR），右 7 个加粗法务链接。所有链接指向主站绝对地址；≤ 1024px 品牌栏上移、链接 2 栏，≤ 560px 单栏。登录 / 注册 / 忘记密码为分栏页，保留品牌区内的迷你页脚，不嵌入完整页脚。

## 6. 无障碍

- 所有输入框有 `<label for>`；OTP 六格各有 `aria-label`；眼睛按钮 `aria-pressed` + `aria-label`。
- 横幅 `role="alert"`；焦点可见（深藏青环）；颜色对比：深藏青 on 白 11.9:1；文字灰 `#6D7C79` on 白 4.6:1；警告文字 `#8A5A0B` on 白 4.9:1；暖阳橙原值 `#F5A93F` on 白仅 1.9:1，严禁用于文字。
- 键盘：OTP 支持粘贴 6 位、Backspace 回退；Caps Lock 提示。
