登录页 · 状态机

页面级状态与迁移条件（对应原型右下角“Force state”）

stateDiagram-v2
  [*] --> Idle
  Idle --> Typing: 输入标识符 / 密码
  Typing --> Validation_Error: 提交且前端校验失败
  Validation_Error --> Typing: 修正输入
  Typing --> Loading: 提交且校验通过
  Loading --> Success: 200
  Loading --> Auth_Failed: 401, attempts+1
  Auth_Failed --> Captcha_Required: attempts >= 3
  Captcha_Required --> Loading: 提交含 captcha
  Loading --> Unverified: 403 邮箱未验证
  Loading --> Social_Only: 409 仅社交登录
  Auth_Failed --> Typing: 重新输入密码
  Auth_Failed --> Locked: attempts >= 5
  Locked --> Idle: 15 分钟后自动解锁
  Locked --> ForgotPassword: 点击 Reset password
  Unverified --> Idle: Resend link / Change email
  Social_Only --> Social_Popup: Continue with Google
  Idle --> Social_Popup: 点击 Google / Apple
  Social_Popup --> Success: 已有账号
  Social_Popup --> Finish_Profile: 首次登录，自动建号
  Social_Popup --> Idle: 用户取消弹窗
  Finish_Profile --> Success: Continue / Skip
  Success --> [*]: 302 redirect

Google / Apple 登录（OAuth 2.0 / OIDC）

含首次登录自动注册、账号合并、CASL 营销同意、Apple Hide My Email

sequenceDiagram
  autonumber
  actor U as 用户
  participant W as vanstro.ca 前端
  participant P as Google / Apple
  participant S as Vanstro 后端
  U->>W: 点击 Continue with Google / Apple
  W->>P: 打开授权弹窗（state + nonce + PKCE）
  P-->>U: 账号选择 / Face ID / Hide My Email
  alt 用户取消
    P-->>W: error=access_denied
    W-->>U: 信息横幅“sign-in was cancelled”
  else 授权成功
    P-->>W: authorization code
    W->>S: POST /api/auth/social {provider, code, state}
    S->>P: 交换 token · 校验 id_token 签名 / nonce / aud
    S->>S: 查找 provider_id 或 已验证邮箱
    alt 已关联账号
      S-->>W: 200 + 会话 Cookie
      W-->>U: Signed in → redirect
    else 邮箱已存在但未关联（已验证邮箱）
      S-->>W: 200 自动合并 + 会话
      W-->>U: 提示“已将 Google 关联到现有账号”
    else 新用户
      S-->>W: 201 创建账号（无密码）
      W-->>U: “One last step”：手机号（可选）+ CASL 营销同意（默认不勾选）
      U->>W: Continue / Skip
      W-->>U: Signed in → redirect
    end
  end
  Note over S: Apple 仅首次返回姓名/邮箱，需持久化；
Hide My Email 中继地址需支持邮件发送域校验
