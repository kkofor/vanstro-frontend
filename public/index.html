可交互原型

在浏览器中直接打开。每个页面右下角有 “Prototype · states” 面板，可一键切换到任意状态用于评审。

1 · 用户登录

  • 邮箱 / 手机号 / 用户名 单输入框自动识别
  • 密码可见 / 隐藏切换，Caps Lock 提示
  • “记住我”30 天持久会话
  • 错误提示：通用凭证错误、5 次锁定、未验证邮箱、仅社交账号
  • 3 次失败后 CAPTCHA（含音频替代）；5 次失败锁定 15 分钟
  • 成功后 2.4s 自动跳转，?redirect= 白名单，外域降级 /account
  • Continue with Google / Apple，首次登录自动建号 + CASL 同意
打开原型交互说明

1b · 注册

  • Google / Apple 置顶；Apple Hide My Email 中继说明
  • 姓名 + 邮箱 + 密码：8+ 位、泄露库、无符号规则（NIST 800-63B）
  • Terms 必勾、CASL 营销默认不勾并写明主体地址
  • 邮箱已注册仅在提交后告知（防枚举）；验证邮件 60s 重发
  • 验证成功 → 欢迎优惠 → 自动跳转；Guest 结算一键转账号
  • EN / FR 全量文案，规则清单同步翻译
打开原型交互说明

2 · 忘记密码

  • Step 1 输入账号邮箱（仅邮件，不提供短信码）
  • Step 2 链接已发送：15 分钟一次性、52s 后可重发、重发即作废旧链接
  • Step 3 新密码：8+ 位、泄露库、最近 3 次不可重用、令牌倒计时
  • Step 4 成功反馈：时间戳、购物车不受影响、“Not you? Freeze account”
  • 防枚举文案、限流（3 次/小时）、仅社交账号引导
打开原型交互说明

3 · 个人中心

  • 头像上传 / 拖放 / 圆形裁剪缩放 / 移除（类型、大小、尺寸三重校验）
  • Overview：最近订单、默认地址 + 省税率提示、语言、会员等级、完成度
  • 只读视图默认，Edit 进入编辑；昵称、姓名、性别（含非二元）、生日（每年一次）、语言、省份
  • 修改密码：8+ 位 / 泄露 / 最近 3 次；“接下来会发生什么” 与 “为什么不要求符号”
  • Orders & quotes：筛选表格、状态芯片、tabular 金额、报价审批
  • 设备列表含 IP、可信设备；通讯偏好（CASL）与数据权利（PIPEDA / Law 25）
  • 关联 Google / Apple、两步验证、已登录设备、删除账号
  • 地址簿：添加 / 编辑 / 删除，默认收货 / 账单，邮编与省份交叉校验
  • 支付方式：添加 / 编辑 / 删除银行卡，品牌识别、Luhn、到期提醒、银行拒绝态
打开原型交互说明

4 · 购物车

  • 行内数量步进（上限 50）、移除后 8 秒内可撤销、高价行移除前二次确认 / 转「稍后再买」
  • 库存不足、商品下架、价格变动三种阻断态：结账按钮置灰并说明原因
  • 促销码：生效 / 过期 / 未识别；按省预估 GST / HST / PST / QST，最终以结账页为准
  • 数量变更在途骨架、保存失败 → Retry；EN / FR 随顶栏切换
  • 购物车快照写入 localStorage，结账页与回执沿用同一份商品与折扣
打开原型

5 · 结算 / 支付

  • 三步：Shipping → Review（总额核对 + 同意）→ Payment，再到确认 / 税票
  • 按送达省计算 GST / HST / PST / QST（含 NS 14% HST、QC 法文税行）
  • 卡数据在 Moneris 托管 iframe 中采集（PCI SAQ A），Vanstro 不存 PAN；已存卡仅 CVV
  • PIPEDA 明示同意、隐私通知弹窗、魁北克 Law 25、CASL 营销默认关闭
  • 3-D Secure 挑战、银行拒绝、票据过期等失败态；成功后即时邮件 / SMS 回执，可重发 / 打印

VI 应用规范 · 颜色与职责

四个品牌色各有明确界面职责：深藏青是唯一的主色（含焦点环），青翠绿只表达成功，暖阳橙只用于图形（文字改用加深版 #8A5A0B），中性灰全部沿豆绿灰色相偏移。错误色与警告文字色为白皮书未定义，登记为例外。
